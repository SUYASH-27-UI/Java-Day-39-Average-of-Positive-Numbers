# Java Day 39 - Average of Positive Numbers

## Description
This Java program calculates the average of all positive numbers in an integer array.

## Example
**Array:** `{10, -5, 20, 0, 30, -2}`

**Output:** `Average = 20.0`

## Concepts Used
- Arrays
- For Loop
- If-Else
- Counter Variables
- Average Calculation

## How to Run
1. Save the code as `Main.java`.
2. Compile using `javac Main.java`.
3. Run using `java Main`.
